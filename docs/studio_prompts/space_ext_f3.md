## Space 후속 F3 — 방(초기 반사)과 거리감

전제: 확장 B 완료(C와는 독립이지만 C가 있으면 움직이는 청취자도 지원). 양이 많으므로 **F3-1(지면 반사 + 잔향 보내기) → F3-2(직육면체 방의 영상 음원)** 두 번에 나누어도 됩니다.

### 목표
HOA는 방향만 담습니다. 거리감을 만드는 것은 직접음 대 반사·잔향의 비율과 반사의 도착 시간입니다.
- **F3-1**
  - 지면 반사: 음원을 지면(z = 0, 높이 조절) 아래로 뒤집은 **영상 음원** 하나. 영상 음원도 같은 지연 시간 솔버·도플러·공기 흡수를 거치는 별개의 음원으로 베이킹(반사 계수, 고역 손실). 직접음과의 콤 필터가 통과 시 움직이는 것이 들리는 핵심 효과.
  - 잔향 보내기: 음원별 `send`(거리에 따라 자동 증가하는 기본 곡선 + 레인), 확산 잔향 하나(의존성 없는 FDN 또는 생성한 임펄스의 `ConvolverNode`, 시드 결정론). 바이노럴/HOA 모드에서는 잔향을 저차(0–1차) 확산장으로 인코딩.
  - 기본값: 둘 다 꺼짐(기존 소리 유지). 프리셋 `Open Field`(지면만), `Hall`.
- **F3-2**
  - 직육면체 방(가로·세로·높이, 벽별 흡수 계수)과 **1차(선택 2차) 영상 음원**: 최대 6(또는 18)개의 영상이 각자 도플러를 가집니다. 비용은 음원 수 × 영상 수이므로 상한과 품질 단계(끔/지면/1차/2차)를 두고 실측.
  - 방 밖으로 나가는 궤적 처리(벽 통과 시 감쇠 또는 경고), 방 편집 UI(3뷰에 상자), 청취자·음원이 벽에 가까울 때의 수치 안정.
- 공통: 반사·잔향은 서명에 포함되는 베이킹 항목과 그렇지 않은 항목(잔향 길이·wet)을 구분. Manager 어댑터·Space Master에서도 동일 동작. 글리산도 베이킹에서는 전부 손실(안내).

### 자가진단
영상 음원의 위치·지연·레벨(해석값 대조), 정지 음원의 콤 필터 노치 주파수 = `c / (2Δr)` 계열, 반사 계수 0 → 직접음과 동일, 잔향 임펄스 결정론·에너지 감쇠 시간(RT60 ±10%), 꺼짐 상태 회귀(1e-9), 비용 실측.
