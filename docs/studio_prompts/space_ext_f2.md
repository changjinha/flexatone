## Space 후속 F2 — 스피커 배열 출력 + 사용자 HRIR

전제: 확장 B 완료. HOA 버스(`js/audio/hoa-bus.js`, `js/modules/ambisonics.js`)를 그대로 쓰고 **디코더만 추가**합니다.

### 목표
- **스피커 배열**: 장치 출력이 2채널보다 많을 때(`ctx.destination.maxChannelCount`) HOA를 실제 스피커로 디코드. 배치 프리셋(쿼드, 5.1(LFE 무음), 7.1, 육면체 8, 8각 링, 사용자 정의 방위/고도 표). 기본 디코더 = 모드 매칭 + `maxre`, 선택지 = AllRAD(가상 t-design → VBAP), 불규칙 배열에서의 에너지 보존 정규화. 차수는 배열이 감당하는 최대로 자동 제한(안내 표시).
- 장치가 2채널이면 이 모드는 **꺼진 상태 + 이유**, 대신 "배열용 다채널 WAV 내보내기"(스피커 피드, 채널 순서 표기)는 항상 가능.
- 채널 라우팅 표(스피커 → 출력 채널), 채널별 트림·지연 보정(거리 다른 스피커), 테스트 톤(스피커 하나씩 핑크 노이즈 버스트).
- **사용자 HRIR**: 바이노럴 디코드에서 브라우저 HRTF 대신, 사용자가 불러온 가상 스피커별 HRIR(WAV 쌍 묶음 또는 다채널 WAV; SOFA 파싱은 의존성 없이 가능한 범위만)을 `ConvolverNode`로 사용. 기본은 브라우저 HRTF, 이것은 선택지. 파일은 `core/sample-library.js`처럼 프로젝트 밖 캐시 + 프로젝트에는 해시만 저장하는 방식을 검토.
- 출력 단계(Loudness Manager)는 스테레오 전제입니다(`output-bus.js`). 다채널에서는 페이더만 채널 공통으로 적용하고 분석기는 다운믹스를 보게 하되, **기존 스테레오 경로는 한 줄도 달라지지 않게** 하세요. 변경이 크면 설계안만 보고하고 멈춥니다.

### 자가진단
배열별 디코드의 방향 오차·음량 균일도 실측, 2채널 장치에서의 꺼짐 처리, 다채널 WAV 헤더/채널 순서, 지연 보정 샘플 수, 사용자 HRIR 유무에 따른 그래프 노드 수, 스테레오 경로 회귀(1e-7).
