# 08. Space Studio — 움직이는 음원의 도플러 글리산도

> 공통 용어는 [00_공통개념](00_공통개념.md).

## 1. 목적

**물리 법칙이 글리산도를 만드는** 스튜디오입니다. 고정된 청취자 주위를 음원이 움직이면, 다가올 때 음이 올라가고 멀어질 때 내려갑니다(지나가는 구급차의 사이렌). 음고뿐 아니라 **음량(거리), 좌우 위치(방위), 밝기(공기 흡수), 도착 지연**이 모두 하나의 물리 모델에서 일관되게 나옵니다.

평면도(위에서 본 장면)에 경로를 그리면, 그 공간적 움직임이 소리의 움직임으로 번역됩니다. Chaos·Cloud·Wave의 스테레오 폭은 단순히 보이스를 좌우로 펼치는 것이지만, Space의 패닝은 **청취자 기준 방위각에서 물리적으로 계산**됩니다(HRTF 선택 가능).

## 2. 신호 흐름

```
음원 경로 X(τ), 속도 v(τ) (호 길이 매개화, |v| ≤ 0.98c)
청취자 L (고정), 방향 heading

지연 시간 방정식:   t = t_e + |X(t_e) − L| / c_eff         ← 듣는 시각 t ↔ 방출 시각 t_e
반경 속도           v_r = d|X − L|/dt_e   (+ = 멀어짐)
관측 음고           f_obs = f_s(t_e) / (1 + v_r/c)
거리 게인           g = refDist / max(r, refDist)
공기 흡수           f_c = clamp(18000/(1 + r/airDist), 800, 20000)
패닝               pan = sin θ  (θ = 청취자 기준 방위)
→ 오실레이터 → 로우패스 → 패너(등전력/HRTF) → 출력 단계 (스테레오)
```

## 3. 기능별 — 수학적 역할과 소리

### 3.1 전역 물리

| 기능 | 수학 | 소리 |
|---|---|---|
| 음속 c | 343 m/s (20 °C) | 현실 기준 |
| c 배율 (예술용) | `c_eff = c·배율` | 줄이면 자전거 속도에서도 수 반음 도플러. 0.3이면 30 m/s 음원이 v/c ≈ 0.29 |
| 최대 v/c 배지 | `f_obs/f_s = 1/(1 + v_r/c)` | 다가오면 `c/(c−v)`배, 멀어지면 `c/(c+v)`배. 1에 가까우면 극단적 급강하 |
| 초음속 클램프 | `|v| ← min(|v|, 0.98c)` | 소닉 붐(해가 여러 개)을 피하려 제한 |
| 기준 거리 | 역거리 법칙, refDist 안은 1 | 거리 두 배 = −6 dB |
| 공기 흡수 거리 | 로우패스 컷오프가 거리 따라 내려감 | 멀수록 먹먹해짐 (먼 천둥) |
| 청취자 위치 / 방향 | 기준점, 0° = +y 시계방향 | 정면/좌우 기준 |
| 패닝 방식 | 등전력 `L²+R²=1` / HRTF | HRTF는 헤드폰에서 앞뒤·위아래 느낌까지 |
| 베이킹 비율 | 100/200/400 Hz | 곡선 정밀도 |

### 3.2 경로 종류

| 경로 | 수학 | 소리 |
|---|---|---|
| 직선 | `X(s) = A + s·(B−A)/|B−A|` | 고전적 "지나가기". 최단 거리 d가 작을수록 **급강하가 날카로움**, 멀면 완만한 S자 |
| 궤도 | `C + (rx cos φ, ry sin φ)` | 청취자가 중심이면 v_r = 0이라 음고 불변(팬만 회전). 중심을 벗어나면 주기적 비브라토 |
| 리사주 | `C + (ax sin(2πau + δ), ay sin(2πbu))` | 정수비 a:b 패턴의 복잡한 주기적 음고·팬 움직임 |
| 나선 | 반지름 r0 → r1, 회전 | 다가오는 나선: 음이 오르며 소리가 머리 주위를 돔 |
| 그린 경로 | Catmull-Rom (최대 64점) | 자유 궤적 |
| 정지 | f_obs = f_s | 비교용: 지연·거리·팬·흡수만 |

### 3.3 음원별 설정

| 기능 | 수학 | 소리 |
|---|---|---|
| 시작 / 길이 | 들리는 구간 `t_e + r(t_e)/c` | **도착 지연**: 멀리서 출발하면 늦게 들림 |
| 높이 h | `r = √(dx² + dy² + h²)` | 머리 위를 지나가면 팬 → 0, 최대 음량 제한 |
| 속도 / 속도 곡선 | 일정 v 또는 `v(τ) = 시작 + (끝−시작)·y(τ/T)` | 가속하며 다가오면 음고가 계속 올라감 |
| 음원 음고 f_s / 음고 곡선 | `f_s = f₀(f₁/f₀)^y` | 음원 자체의 글리산도에 도플러가 곱해짐 (사이렌 + 이동) |
| 효과 토글 | 도플러 / 거리 게인 / 공기 흡수 / 패닝 각각 끄기 | **효과를 하나씩 꺼서 각 물리 요소의 기여를 분리해 들을 수 있음** |
| 기본 게인, 음색 | 재베이킹 없음 | 밝은 음색일수록 공기 흡수가 잘 들림 |

### 3.4 시각화

| 뷰 | 의미 |
|---|---|
| 장면의 파면 링 | 반지름 `c·(t − t_e)`. 진행 방향 앞에서 촘촘(음고↑), 뒤에서 성김(음고↓) — 도플러의 그림 |
| 관측 음고 | f_obs(t) 실선, f_s 점선. 둘의 차이가 도플러 계수 |
| 게인·팬·거리 레인 | 청취자 시간 기준 |

## 4. 들어보기 실험

1. **지나가기 거리**: 직선, 20 m/s. 최단 거리 d를 1 m → 20 m로. 가까우면 "휙" 급강하, 멀면 완만.
2. **c 배율**: 0.1로 내리면 걷는 속도에서도 큰 글리산도.
3. **효과 분리**: 도플러만 끄고 들으면 음고는 고정, 음량·팬·밝기만 지나갑니다.
4. **궤도 중심 이동**: 청취자 중심 궤도(음고 불변) → 중심을 옆으로 옮기면 주기적 비브라토가 생김.

## 5. 베이킹 시 손실

음원 하나 = 보이스 하나(최대 64), 도착 시각에 시작. f_obs(t)와 거리 게인만 남고 **팬, HRTF 방향, 공기 흡수 필터는 사라집니다.**
