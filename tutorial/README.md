# Flexatone 스튜디오 튜토리얼

스튜디오마다 **① 목적 → ② 신호 흐름 → ③ 기능별 수학적 역할과 소리에 미치는 영향 → ④ 들어보기 실험 → ⑤ 글리산도로 베이킹할 때 사라지는 것** 순서로 정리했습니다.

화면 조작법(단축키, 버튼 위치)보다는 **"이 손잡이가 수학적으로 무엇을 하고, 그래서 소리가 어떻게 바뀌는가"**에 집중합니다. 각 컨트롤의 짧은 설명은 앱에서 `Alt`를 누른 채 마우스를 올리거나 `H`(도움말 모드)로도 볼 수 있습니다.

## 읽는 순서

1. **[00_공통개념](00_공통개념.md)** — 정규화 곡선, 로그 음고, 곡선 엔진 14종, 5파형 음색, 1/√N, 출력 단계, 베이킹. *먼저 읽기를 권합니다.*
2. **[01_Glissando](01_Glissando.md)** — 모든 스튜디오의 결과가 모이는 기본 스튜디오.
3. 나머지는 관심 순서대로.

## 스튜디오 고르기 — "이런 소리를 원하면"

| 원하는 소리 | 추천 |
|---|---|
| 정확히 내가 정한 모양의 글리산도 | Glissando |
| 끝없이 올라가는 사이렌 / 끝없는 아첼레란도 | Risset |
| 관성·소용돌이가 있는 자연스러운 궤적, 음계에 달라붙는 글리산도 | Field |
| 즉흥적인 손 제스처, 도형을 소리로 | Draw |
| 같이 시작해서 예측 불가하게 갈라지는 선율 | Chaos |
| 빗소리·벌떼 같은 수천 개 입자 질감 | Cloud |
| 같은 선율이 서로 다른 속도로 어긋나고 만나는 리듬 | Tempo |
| 지나가는 차, 머리 주위를 도는 소리 | Space |
| 확대해도 닮은 장식 선율, 가지 치는 화음 | Fractal |
| 퍼지고 반사되고 증식하는 음고 패턴 | Wave |
