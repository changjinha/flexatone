# 10. Wave Studio — 음고 축을 매질로 쓰는 파동

> 공통 용어는 [00_공통개념](00_공통개념.md).

## 1. 목적

**음고 축 자체를 "줄(string)"로 보고 그 위에 파동 방정식을 흘립니다.** 세로축의 음고 빈(기본 128개)이 줄의 격자점이고, 그 점의 진폭이 그 음고의 음량이 됩니다.

- 펄스 하나가 줄 위를 이동하면 → **글리산도**
- 펄스가 퍼지면 → **구름**
- 정상파가 서면 → **화음** (배 위치의 음이 맥동)
- 솔리톤이 충돌하면 → **교차하는 두 글리산도**
- 반응-확산 패턴이 자라면 → 음역 전체로 번지는 **증식하는 질감**

즉, 편미분방정식의 시공간 패턴을 그대로 "시간 × 음고" 악보로 듣는 스튜디오입니다.

## 2. 신호 흐름

```
방정식 (wave / Klein–Gordon / sine-Gordon / Gray–Scott)
+ 매질 c(x), 경계, 초기 조건, 구동 지점
  → Störmer–Verlet(leapfrog) 또는 양해 오일러로 베이킹
  → 행렬 E[시간][음고 빈]   (bakeRate 100 Hz)
소리화:
  A. 스펙트럴 뱅크:  y = scale·Σ aᵢ(t)·sin(2πfᵢt + φᵢ),  aᵢ = clamp(g·sᵢ^γ)
  B. 리지 → 보이스:  극대점을 추적 → 최대 K개 글리산도 보이스
```

음고 빈 i의 주파수는 고정입니다: `fᵢ = 440·2^((pLo + i·Δx − 69)/12)`, `Δx = (pHi − pLo)/(Nx − 1)` 반음.

## 3. 기능별 — 수학적 역할과 소리

### 3.1 방정식

| 방정식 | 수식 | 소리 |
|---|---|---|
| 파동 | `u_tt = c(x)²(u_xx − D·u_xxxx) − γu_t` | 펄스가 둘로 갈라져 위/아래로 글리산도, 벽에서 반사 |
| 클라인–고든 | `u_tt = c²u_xx − m²u`, `ω² = c²k² + m²` | 질량 항 때문에 분산: 펄스 뒤에 떨리는 꼬리(잔향 같은 글리산도 무리) |
| 사인-고든 | `u_tt = c²u_xx − m²sin u`, 킨크 `u = 4·atan exp((x−vt)/(w√(1−v²/c²)))`, `w = c/m` | **솔리톤**: 모양을 유지하며 이동하는 입자. 두 킨크가 충돌 후에도 그대로 통과 → 서로 지나치는 두 글리산도 |
| 그레이–스콧 | `u_t = Du u_xx − uv² + F(1−u)`, `v_t = Dv v_xx + uv² − (F+k)v` | 씨앗 펄스가 자라고 쪼개져 음역을 채움 — 생물처럼 증식하는 화음 |

### 3.2 격자와 시간

| 기능 | 수학 | 소리 |
|---|---|---|
| 음고 빈 Nx | 격자점 수 | 많을수록 음고 해상도↑, 펄스가 날카로움. 오실레이터 수도 증가 |
| 음역 pLo–pHi | 줄의 길이 | 넓히면 같은 파속에서 횡단 시간이 길어짐. 0.45·fs 넘는 빈은 뮤트 |
| 길이 | `T_sim = length·simSpeed` | 곡 길이 |
| 베이킹 레이트 | `frames = length·bakeRate + 1` | 시간 해상도 (오디오는 프레임 사이 선형 보간) |
| 시뮬 속도 | `t_model = simSpeed·t` | 물리는 그대로, 전체를 빠르게/느리게 |
| CFL 목표 | `Δt = min(CFL,1)·Δx/c_max` (GS: `D·Δt/Δx² ≤ 0.5`) | 안정성. 1 근처가 수치 분산 최소. 낮추면 날카로운 펄스에 잔물결 |
| 에너지 오차 ΔE | `E = ½Σ(u_t²/c² + u_x²)Δx` | 보존계에서 시뮬레이션이 정확한지 확인 |

### 3.3 매질과 물성

| 기능 | 수학 | 소리 |
|---|---|---|
| 파속 c | 모델 1초당 반음. 12 = 초당 한 옥타브 | **글리산도 속도** 그 자체 |
| 매질 곡선 c(x), 범위 | `c(x) = c·lerp(min, max, y(x))` | 음역마다 파속이 다름 → 특정 음역에서 가속, 경로가 휨(굴절) |
| 감쇠 γ | 진폭 `e^(−γt/2)` | 소리가 서서히 사라짐 |
| 분산 D (강성) | `ω² = c²k²(1 + Dk²)` | 짧은 파가 빨라 펄스가 **처프**로 퍼짐 (빠른 잔물결이 앞서감) |
| 질량 m | KG 분산 세기 / SG 킨크 폭 `w = c/m` | |
| 확산 Du, Dv / 공급 F / 소멸 k | 그레이–스콧 | Du > Dv(약 2:1)일 때 패턴. F≈0.03, k≈0.057에서 증식 |

### 3.4 경계

| 경계 | 수학 | 소리 |
|---|---|---|
| 고정 | u = u₀ | 반사 시 **부호가 뒤집힘** (색 반전) |
| 자유 | u_x = 0 | 부호 유지 반사 |
| 흡수 | `u_t ± c·u_x = 0` (Mur) | 파가 빠져나가 사라짐 — 한 번 지나가는 글리산도 |
| 순환 | 위 끝 ↔ 아래 끝 연결 | 위로 나간 펄스가 아래에서 등장 (셰퍼드 같은 순환) |

### 3.5 초기 조건과 구동

| 기능 | 수학 | 소리 |
|---|---|---|
| 가우시안 / 삼각 / 사각 펄스 | 위치, 폭, 진폭 | 출발 음고와 음 덩어리 크기 |
| 발사 방향 v | `u_t(x,0) = −v·c·u_x` | +1 위, −1 아래 (글리산도 하나), 0이면 둘로 갈라짐 |
| 정상파 모드 n | `u = sin(nπx/L)`, `Tₙ = 2L/(n·c)` | n개의 배 = n개 음이 맥동하는 화음. 여러 모드 합 = 복합 화음 |
| 킨크 | 2π 계단 (+킨크 / −반킨크) | 사인-고든 솔리톤 |
| 노이즈 | 시드 | 무작위 시작 |
| 구동 지점 | `… + S·cos(2πf(t−t₀))·δ(x−x₀)`, 파장 `λ = c/f` | 한 음고에서 파를 계속 방출 → 그 음에서 위아래로 퍼지는 글리산도 물결. f는 모델 Hz(오디오 주파수 아님) |

### 3.6 소리화

| 기능 | 수학 | 소리 |
|---|---|---|
| 스펙트럴 뱅크 | 빈 = 고정 주파수 사인, 진폭만 변화 (AudioWorklet) | 조밀한 구름 질감. 이동 펄스 = 미끄러지는 클러스터 |
| 리지 → 보이스 | 프레임별 극대점을 예측 위치 최근접으로 매칭 | 또렷한 선. 베이킹이 보내는 것과 같음 |
| 원천 | `|u|` / 국소 에너지 `½(u_t² + c²u_x²)` / (GS: v 또는 uv²) | 에너지는 움직이는 덩어리만 따름 → 킨크에 적합 |
| 게인 / 진폭 지수 γ | `a = clamp(g·s^γ, 0, 1)` | γ>1: 가장 강한 리지만, γ<1: 약한 잔물결도 들림 |
| 바닥값 | `a = 0 (s^γ < floor)` | 노이즈 플로어 제거 |
| 스테레오 폭 | `pan = width·(2(p−pLo)/(pHi−pLo) − 1)` | 낮은 음 왼쪽, 높은 음 오른쪽 |
| 피크 임계 / 최대 트랙 / 최대 이동 / 최대 공백 | 리지 추적 규칙 | 트랙 수와 연속성. 공백은 영점 통과·교차를 이어 줌 |
| 리지·베이킹 음색 | 5파형 | 스펙트럴 뱅크는 항상 순수 사인(음색 = 파동장 자체) |

## 4. 들어보기 실험

1. **단일 펄스**: 중앙 펄스, 발사 0, 고정 경계. 둘로 갈라져 위/아래 글리산도 → 반사(부호 반전).
2. **경계 비교**: 같은 설정에서 흡수(사라짐) vs 순환(끝없이 돌기).
3. **정상파 화음**: 모드 3, 5, 8. 고정된 음들이 서로 다른 주기로 맥동.
4. **분산**: D를 올리면 깨끗한 펄스가 처프로 번집니다.
5. **킨크 충돌**: 사인-고든, 원천 = 국소 에너지. 두 글리산도가 교차 후 그대로 진행.

## 5. 베이킹 시 손실

리지 트랙 하나 = 보이스 하나(최대 64). 스펙트럴 모드는 먼저 리지로 근사됩니다. **스테레오 위치, 빈 위상, 피크 임계값 아래의 모든 것은 사라집니다.**
