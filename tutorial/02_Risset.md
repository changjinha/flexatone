# 02. Risset Studio — 끝없이 올라가는(내려가는) 착청

> 공통 용어는 [00_공통개념](00_공통개념.md). 화면 조작은 루트의 [risset.md](../risset.md).

## 1. 목적

**셰퍼드–리세 톤(Shepard–Risset glissando)**: 계속 올라가는데 절대 높아지지 않는 소리를 만듭니다. 여기서 출발해 리듬(끝없는 아첼레란도), 순정 화성, 입자 명멸, 상호작용하는 보이스 군집까지 확장되어 있습니다.

핵심 아이디어는 **음고를 직선이 아니라 원(S¹) 위에 둔다**는 것입니다. 원 위를 계속 돌면 위로 나간 보이스가 아래로 다시 들어옵니다. 그 이음새를 **스펙트럼 포락선(벨)**이 소리 없이 숨깁니다.

## 2. 신호 흐름

```
마스터 위상 φ(τ) = wrap(φ₀ + v·F(τ))          ← 속도 v, 궤적 셰이핑 F
보이스 위상  pᵢ  = wrap(φ + offᵢ/span)          ← 화성 오프셋 격자 / 동역학 xᵢ
음고         fᵢ  = 440·2^((base + pᵢ·span − 69)/12)
진폭         Aᵢ  = A_global(pᵢ) · A_local,i · (영역·떨림 대역 등)
출력         y   = masterGain · (1/√N) · 0.65 · Σ Aᵢ·wave(ψᵢ)  → 파라메트릭 EQ → 출력 단계
```

## 3. 기능별 — 수학적 역할과 소리

### 3.1 위상·음고 코어 (S¹)

| 기능 | 수학 | 소리 |
|---|---|---|
| 글리산도 속도 v | `φ(τ) = wrap(φ₀ + v·F(τ))`, 순환 주기 `T = B/(N·|v|)` | +는 끝없는 상승, −는 하강, 0은 정지 화성(Freeze). |v|가 크면 사이렌, 작으면 빙하처럼 느린 흐름 |
| 보이스 수 N | 2–60, `1/√N` 자동 보정 | 적으면 개별 선이 들림, 많으면 매끄러운 "띠" (착청이 더 강해짐) |
| 스팬 & 기준 MIDI | 원 한 바퀴 = `[base, base+span]` 반음 | 기본 C1 + 96(8옥타브). 스팬이 좁으면 착청이 약해지고 반복이 들림 |
| 궤적 셰이핑 F | 선형 / 코사인(주기마다 쉼) / 사인(속도 출렁임) / 다항 / 곡선 엔진. 평균 속도 보존 `F(kP)=kP` | 같은 평균 속도에서 "계단식으로 쉬었다 가기", "숨 쉬듯 출렁이기" 등 |
| 마스터 위상 스크럽 | 캔버스 드래그 = φ 직접 조작 | 손으로 회전을 돌리는 느낌 |

### 3.2 화성 오프셋 격자

| 기능 | 수학 | 소리 |
|---|---|---|
| 등간격 격자 | `I = span/N` | 전형적인 셰퍼드 옥타브 스택 (N=8, span=96이면 옥타브 간격) |
| 비등간격 / 사용자 오프셋 | `offᵢ ∈ [−60, 144]` 반음 | 화음(예: 장3화음 스택)이 통째로 회전하며 올라감 |
| 비율 격자 (순정) | `off_{i+1} = (off_i + 12·log₂(p/q)) mod span` | 3:2 = 701.955¢ 순정 5도 스택 → 평균율보다 맑은 울림 |
| 스트레치 스팬 | `span = 12·log₂R` | R=2 옥타브, 2.1 늘린 옥타브(종 같은 색), 3 트리타브(비옥타브 순환) |
| 폴리리듬-화성 워핑 | `off_i = i·12·log₂(p/q)`, `span = N·12·log₂(p/q)` | 같은 비율이 리듬 대역에서는 p:q 폴리리듬, 톤 대역에서는 p:q 화성 |

### 3.3 스펙트럼 포락선 A_global (착청의 핵심)

| 기능 | 수학 | 소리 |
|---|---|---|
| 모양 | 벨패스 `1/(1+|d|^γ)` · 가우시안 `e^(−d²/2)` · 레이즈드 코사인, `d=(p−c)/σ` | 가장자리 보이스를 숨겨 이음새를 지움. 가우시안은 부드럽고 벨패스는 가운데가 평탄 |
| 중심 c | 벨의 위치 | 소리의 "무게중심" 음역 (어둡게/밝게) |
| 폭 σ | 벨 폭 (1.00 = 전 대역) | 좁으면 한 음역에 모인 띠, 넓으면 착청이 깨지고 위아래 끝이 들림 |
| 비대칭 skew | `σ_L = σ(1−skew)`, `σ_R = σ(1+skew)` | 들어오는 쪽/나가는 쪽 속도 차 → 상승감 강조 |
| 첨도 γ | 벨패스 경사 | 클수록 평탄한 꼭대기 + 가파른 벽 |

### 3.4 로컬 명멸 A_local / 로컬 입자 2.0

| 기능 | 수학 | 소리 |
|---|---|---|
| 랜덤 명멸 | 부드러운 노이즈 + 임계값, S커브 페이드 `A = ½ − ½cos(π·ramp)` | 보이스가 비동기적으로 켜졌다 꺼짐 — 반짝이는 입자 질감 |
| 사인 명멸 | 보이스별 LFO + 하한 | 규칙적인 호흡 |
| 위상 대역 / 주파수 대역 | 대역 안 보이스만 영향 | 특정 음역만 반짝이게 |
| 페이드 모양 κ | `S = cᵃ/(cᵃ+(1−c)ᵃ)` | κ>0: 중간을 빨리 지나는 "깜빡", κ<0: 반쯤 켜진 채 오래 머묾 |
| 페이드 길이 분포 | 균등 / 정규 / 로그정규 | 로그정규는 가끔 아주 긴 페이드 → 불규칙하고 자연스러운 숨 |

### 3.5 파형, 동기화, 리듬 연속체

| 기능 | 수학 | 소리 |
|---|---|---|
| 리듬 ↔ 톤 연속체 | `f_min`을 0.5 Hz부터. 리듬 <12 Hz, 떨림 12–30 Hz, 톤 >30 Hz | 같은 셰퍼드 구조가 낮은 대역에서는 **끝없이 빨라지는 박** (리세 리듬)이 됨 |
| 파형 / 듀티 모핑 | `y = (1−m)sin 2πψ + m·0.8(pulse_d(ψ) − (2d−1))`, PolyBLEP | 사인 → 펄스. 리듬 대역에서 펄스는 "딱딱" 클릭, 듀티 50%는 홀수 배음만 |
| 위상 동기화 K (쿠라모토) | `dψᵢ/dt = fᵢ + K·r·sin 2π(Ψ−ψᵢ)` | K>0: 펄스가 정렬(합쳐진 강한 박), K<0: 흩어짐(흐린 질감). r은 정렬도 |
| 떨림 대역 포락선 | 12–30 Hz 구간만 `W(f)=10^(G·b(f)/20)` | 리듬과 톤 사이의 "부르르" 거칠기만 키우거나 줄임 |

### 3.6 상호작용 동역학 (보이스 = 입자)

보이스 위치 `xᵢ`가 회전 좌표계 위에서 힘을 받아 움직입니다. `pᵢ = wrap(φ + xᵢ)`.

| 힘 / 항 | 수학 | 소리 |
|---|---|---|
| 차수 0/1/2/지연 | 평형 배치 / 이완 / 관성 / t−τ 결합 | 2차는 관성 때문에 출렁이며 자리를 찾음, 지연은 캐논처럼 따라옴 |
| 쿠라모토–사쿠라구치 인력 | `K/N Σ sin(2π(Δᵢⱼ−δᵢⱼ) − α)` | 보이스가 격자 간격으로 모임. α(좌절)는 회전·소용돌이를 만듦 |
| 임계 대역 척력 | 가까운 보이스를 밀어냄 | 반음 이하로 붙어 거칠어지는 것을 막음 |
| 점성 (층류/난류) | `μ Σ k(uᵢ ∓ uⱼ)` | 움직임이 끈적하게 함께 감 |
| 질량·부력 | `m = m₀ + Mᵢ`, `Mᵢ = A_g·A_l`, `Bᵢ = β·A_l·|∂A_g/∂p|` | 큰(무거운) 보이스는 가라앉고 작은 보이스는 떠오름 → 대류 같은 순환 |
| Boids, 저항, 잡음 | 정렬·분리 + 시드 잡음 | 떼 지어 움직이는 군집 |

적분: 100 Hz RK4, 속도·가속도는 부드럽게 포화.

### 3.7 화성 색채와 제어기

| 기능 | 수학 | 소리 |
|---|---|---|
| R · H · C 분석 | Plomp–Levelt 거칠기 R, 임계대역 쌍 H, 스펙트럼 중심 `C = Σa log₂f/Σa` | 지금 소리가 얼마나 거칠고(R) 얼마나 밝은지(C) 실시간 수치 |
| 색채 불변성 제어기 (PI) | `u = base + dir·range/16·(Kp·e + Ki∫e)` | 화음이 회전해도 밝기나 거칠기를 **일정하게 유지**하도록 포락선 등을 자동 조정 |

### 3.8 영역 모듈 · 공간 회전 · 기타

| 기능 | 수학 | 소리 |
|---|---|---|
| 영역 모듈 (≤6) | `A = A_global(s)·A_local·gain·edge(s)`, s ∈ [lo, hi] | 음역마다 따로 도는 리세 음장 — 예: 저음은 하강, 고음은 상승 |
| 공간 회전 θ | `a = (s−c)sinθ`, `y = c + (s−c)cosθ` | 180°=거울(상승↔하강), ±90°=시간축을 음고로 → 궤적이 선을 지날 때마다 음이 생김 |
| 파라메트릭 EQ | RBJ 피킹 바이쿼드, 콤 필터 | 특정 대역 강조. 콤은 옥타브 간격 ±7 dB |
| 루핑 오토메이션 | `eff = base + (y(u)−½)(max−min)/2` | 노브를 루프마다 자동으로 흔듦 |
| 오디오 엔진 | 워클릿: 샘플마다 위상 진행 | 어떤 속도에서도 정확한 래핑. 오실레이터 폴백은 사인만 |

## 4. 들어보기 실험

1. **착청 깨뜨리기**: 포락선 σ를 1.00까지 올리면 맨 위에서 사라지고 맨 아래에서 튀어나오는 보이스가 들립니다. 다시 좁히면 끝없는 상승이 돌아옵니다.
2. **리세 리듬**: 리듬↔톤에서 `f_min`을 1 Hz 근처로, 파형을 펄스로. 끝없이 빨라지는 박이 됩니다.
3. **순정 5도 회전**: 비율 격자 3:2. 평균율보다 맑고 정지된 화음이 회전합니다.
4. **대류**: 동역학 2차 + 질량·부력 켜기. 큰 보이스와 작은 보이스가 서로 반대로 흐릅니다.

## 5. 베이킹 시 손실

각 보이스는 래핑 지점(위→아래)에서 잘려 별도 커스텀 보이스(최대 64)가 되고 포락선은 게인 점이 됩니다. **끝없음은 사라지고**(유한 길이), EQ·동기화·펄스 파형·영역 회전 같은 실시간 처리도 옮겨지지 않습니다.
