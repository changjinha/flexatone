# 07. Tempo Studio — 템포 캐논 (낸캐로 · 라이히 · 리게티)

> 공통 용어는 [00_공통개념](00_공통개념.md).
> 주의: **템포 매니저(Tempo Manager)**는 트랙 전체 재생 속도를 바꾸는 별개 기능입니다. 둘을 같이 쓰면 배속이 곱해집니다: `실효 배속 = 매니저 배속 × rᵢ(u)`.

## 1. 목적

**같은 주제(선율)를 여러 보이스가 각자 다른 템포로 동시에 연주**합니다. 음고가 아니라 **시간 구조**를 작곡하는 스튜디오입니다.

- 낸캐로: 3:4:5 같은 템포 비율의 보이스들이 정해진 순간에 **한 점으로 수렴**하는 캐논.
- 라이히: 거의 같은 템포의 두 보이스가 천천히 어긋났다 다시 맞는 **페이징**.
- 리게티: 가속하는 보이스들이 서로 미끄러지는 **폴리템포 텍스처**.

## 2. 신호 흐름

```
주제 S(s): 노트 편집기 (음고, 박 길이, 글라이드) 또는 글리산도 보이스 곡선
주제 길이 L = Σ 박ᵢ · 60/BPM

보이스 i:
  배속 rᵢ(u)  ← 고정 / 곡선 / 수렴 비율
  악보 위치    sᵢ(u) = s0ᵢ + ∫₀ᵘ rᵢ(x) dx       (사다리꼴 2000 스텝)
  음고        pitchᵢ(u) = S(sᵢ(u) mod L) + 조옮김
  (+ 펄스 레이어: 주제의 매 박마다 클릭)
```

u = 실제 시간(곡 시간), s = 주제 안의 위치. **배속은 s의 기울기**입니다.

## 3. 기능별 — 수학적 역할과 소리

### 3.1 주제

| 기능 | 수학 | 소리 |
|---|---|---|
| 노트 편집기 | 음고, 박 단위 길이, 글라이드(이전 음에서 미끄러지는 비율) | 모든 보이스가 공유하는 선율. 글라이드 0 = 새 어택 |
| 주제 BPM | `L = Σ dᵢ·60/BPM` | 주제 1회 길이의 기준 |
| 주제 소스 | 노트 또는 글리산도 보이스 곡선 | 글리산도를 캐논으로 |
| 시드 | 무작위 주제 생성 | 같은 시드 = 같은 주제 |

### 3.2 템포 모드 (보이스별)

| 모드 | 수학 | 소리 |
|---|---|---|
| 고정 배속 | `s(u) = s₀ + r·u` | 2 = 두 배 빠르게. 악보 위치 그래프에서 직선 |
| 곡선 (아첼/리타) | lin `r = lo + (hi−lo)·c(u/T)` · log `r = lo·(hi/lo)^c` | 점점 빨라지거나 느려짐. **log 보간은 같은 비율이 같게 느껴짐**(귀에 고른 가속) |
| 수렴 비율 | `rᵢ = ρᵢ·r₀` | 캐논의 템포 비율 |
| 시작 위치 s₀ | 음수 = 늦게 진입 | 배속 1에서 s₀ = −2면 2초 뒤 진입 |
| 조옮김 / 옥타브 | 음고만 이동 | 타이밍과 무관 (재베이킹 없음) |
| 반복 | 켜면 `s mod L` | 끄면 한 번만 |

### 3.3 캐논 구조

| 기능 | 수학 | 소리 |
|---|---|---|
| 수렴 캐논 | `s₀ᵢ = sc − ρᵢ·r₀·Tc` (곡선은 적분값으로) | 템포가 다른 보이스들이 시각 Tc에 같은 악보 위치 sc에 **동시에 도착** — 혼돈이 한순간 유니즌으로 정렬 |
| 비율 ρ / 기준 r₀ | `rᵢ = ρᵢ·r₀` | 3:4:5, r₀=0.25 → 0.75×, 1×, 1.25× |
| 페이징 ε | 보이스 i 배속 × `(1 + i·ε)`, `Δs(u) = ε·u` | 처음엔 유니즌 → 에코 → 서로 다른 박에 걸친 복잡한 리듬 → `L/ε`초 뒤 다시 유니즌 |
| 프리셋 | 낸캐로 3:4:5 · 라이히 페이즈 · 아첼레란도 부채꼴 · 황금비 1:φ:φ² · 시차 캐논 | 황금비는 비율이 무리수라 **다시는 맞지 않음** |

### 3.4 펄스 레이어

| 기능 | 수학 | 소리 |
|---|---|---|
| 펄스 | 보이스마다 매 박 클릭, 루프 시작 강조, `f_tick,i = 800·2^(i/3)` Hz | 각 보이스의 박이 서로 다른 음높이 클릭으로 들려 폴리템포가 귀에 분명해짐 |

### 3.5 분석 뷰

| 뷰 | 수학 | 의미 |
|---|---|---|
| 악보 위치 그래프 | x = 시간, y = sᵢ(u) | 직선 = 고정 템포, 곡선 = 가속. 선이 만나는 점 = 같은 순간 같은 음. ◆(Tc, sc) 드래그 |
| 위상차 행렬 | `φᵢⱼ = ((sᵢ−sⱼ) mod L)/L` | 밝을수록 동기. 수렴 캐논은 Tc에서 모두 0, 페이징은 일정 경사 |
| 주제 롤 | 점 = `sᵢ(u) mod L` | 같은 선율 위를 서로 다른 속도로 지나는 모습 |

## 4. 들어보기 실험

1. **라이히 페이즈**: 보이스 2개, ε = 0.02, 펄스 켜기. 유니즌 → 에코 → 교차 리듬 → 다시 유니즌 (L/ε초 주기).
2. **낸캐로 수렴**: 3:4:5, Tc를 곡 끝으로. 마지막에 세 보이스가 한 음으로 착지합니다.
3. **log vs lin 가속**: 곡선 모드 0.5× → 2×. lin은 끝에서 갑자기 빨라지고, log는 고르게 가속합니다.

## 5. 베이킹 시 손실

루프 하나 = 글리산도 보이스 하나(구간 선형, 최대 64 — 넘으면 시간순 앞 64개). 베이킹 모양 "연속"은 60 ms 글라이드 레가토, "계단"은 10 ms 램프 + 게인 골. **펄스 레이어는 사라집니다.**
