# 01. Glissando Studio — 궤적을 직접 설계하는 기본 스튜디오

> 먼저 [00_공통개념](00_공통개념.md)을 읽으면 좋습니다. 화면 조작(단축키, 숫자 드래그)은 루트의 [glissando.md](../glissando.md)에 있습니다.

## 1. 목적

**한 보이스가 시간에 따라 음고를 어떻게 움직일지를 수학 함수로 직접 정하는 곳**입니다.

- 다른 9개 스튜디오는 규칙(물리, 확률, 카오스 …)이 궤적을 *대신* 만들어 줍니다. Glissando는 내가 궤적을 *직접* 씁니다.
- 다른 스튜디오의 "글리산도 보이스로 베이킹" 결과가 모두 여기로 들어옵니다. 즉 **최종 편집실**이기도 합니다.

음악적 레퍼런스: 크세나키스 *Metastaseis*의 현악 글리산도, 펜데레츠키의 클러스터 글리산도, 전자음악의 피치 스윕.

## 2. 신호 흐름

```
곡선 엔진 y(t) ∈ [0,1]  ──(음고 스케일: 로그/선형)──▶  f(t) = F₀·(F₁/F₀)^y
게인 엔벨로프 e(t)       ──(단위: amp/dB/sone)────▶  a(t) = baseGain · e(t) · 트레몰로
음색 (5파형 / f(x))      ──▶ PeriodicWave
                         ──▶ 오실레이터 ──▶ 게인 버스(1/√N 등) ──▶ 출력 단계
```

## 3. 기능별 — 수학적 역할과 소리

### 3.1 음고 & 타이밍

| 기능 | 수학적 역할 | 소리에 미치는 영향 |
|---|---|---|
| F₀ / F₁ | 정규화 곡선 y=0, y=1이 대응하는 주파수 | 글리산도의 출발음·도착음. 간격이 클수록 극적인 스윕 |
| 음고 스케일 (로그/선형 Hz) | `F₀(F₁/F₀)^y` vs `F₀ + (F₁−F₀)y` | 로그: 고르게 들림. 선형: 아래에서 빠르고 위에서 느린 것처럼 들림 |
| 시작 / 길이 | 시간 정규화 `t_n = (t − start)/dur` | 같은 모양을 빠르게(긴장) 또는 느리게(명상적) |
| 센트 미세 조정 | `f·2^(c/1200)` | 두 보이스를 몇 센트 어긋나게 하면 맥놀이(beating)가 생김 |

### 3.2 곡선 엔진 — 파라미터별 의미

| 엔진 | 파라미터 | 수학적 역할 | 소리 |
|---|---|---|---|
| 조화 S-회전 | 피벗각 α, 변곡점 x₁·x₂, 대칭 잠금 | `½(1−cos πφ)`에 `((tan α − π/2)/2π)·sin 2πφ·sin πφ` 를 더해 S커브를 비틂 | α>0: 앞에서 빨리 올라감, α<0: 늦게 몰아서 올라감. 변곡점은 "가장 빠른 순간"의 위치 |
| 감쇠진동 | t₀, A, N, k, C¹/C⁰ | t₀ 이후 `1 + A·e^(−kτ)·sin(2πNτ)` | 도착음 주변 출렁임. N=진동 횟수(비브라토 속도), k=잦아드는 속도, A=폭. C⁰은 "탁" 부딪히는 날카로운 도착 |
| 탄도형 예비동작 | 후퇴 d, 발사 타이밍 t_w, 가속 p, 오버슈트 r | `t^p − d·B(t;t_w) + r·9.48 t⁴(1−t)` | 반대로 살짝 내려갔다(d) 확 치고 올라가고(p) 목표를 지나쳤다(r) 돌아옴 — 몸짓 같은 글리산도 |
| 미분음 래칫 | 계단 수 N, 라운딩 σ | `(⌊Nt⌋ + smooth_σ({Nt}))/N` | N=12에 1옥타브면 반음 계단(반음계). σ→1이면 계단이 녹아 연속 글리산도 |
| 비브라토 스윕 | 깊이 A, 속도 f₀→f₁ | 순간 주파수가 선형으로 변하는 처프 `sin 2π(f₀t + ½(f₁−f₀)t²)` | 오르면서 비브라토가 가속(f₁>f₀)하거나 감속 |
| 탄성 바운스 | 횟수 N, 감쇠 k, 리듬 가속 p | `1 − e^(−kt)(1−t⁶)|cos(…t^p)|` | 목표음에 튕기며 안착. p>1이면 튕김 간격이 점점 짧아짐(공 떨어뜨리기) |
| 베지어 | P₁, P₂ | 3차 베지어, x=t로 역산 | 가장 자유로운 이징. y를 0–1 밖으로 내면 오버슈트 |
| 경유 정체 | t_m, y_m, W | C² 5차 선반 | 중간 음(y_m)에서 W만큼 머무름 — "경유지" 있는 글리산도 |
| 다항 | 점 목록 | 라그랑주 보간 | 점을 정확히 지나지만 점이 많으면 사이에서 크게 출렁임(룽게 현상) |
| 모핑 | 노드 + 가중치 w, Blend/Add/Mul/Diff | `fold(op, wᵢ·Engineᵢ(t))` | 예: 지수 상승 + 감쇠진동 = 가속하며 올라가 출렁이며 도착 |
| 커스텀 | 앵커와 핸들 | 구간별 베지어 스플라인 | 완전한 손 편집. **수식으로 근사** 버튼은 가장 가까운 수식 엔진을 찾아 줌(RMSE 표시) |
| 지수/로그 | k | `(e^{kt}−1)/(e^k−1)` / `ln(1+(e^k−1)t)/k` | 지수: 끝에서 몰아치는 상승(사이렌 시작), 로그: 처음에 튀고 서서히 안착 |
| 삼각·역삼각 | 함수, x₀–x₁, 진폭, 바이어스 | 구간 `[x₀,x₁]`의 g(x)를 0–1로 정규화 | sin 여러 주기 = 비브라토형, atan = 부드러운 포화 |
| 사용자 수식 | 식, 변수 a, b … | `f(t; a, b …)`, 정규화 선택 | 어떤 수학 함수든 소리로 |

**시간 반전/값 반전**: `f(1−t)`, `1−f(t)` — 같은 제스처의 역행·전위(대위법의 기본 변형).

### 3.3 게인 엔벨로프

| 기능 | 수학 | 소리 |
|---|---|---|
| 포인트 / 곡선 엔진 소스 | 스플라인 또는 엔진 곡선 e(t) | 음량 모양 |
| 진폭 범위 / 자동 맞춤 | `g = min + (max−min)·f(t)` | 엔진 곡선을 음량 범위로 펼침 |
| 엔벨로프 단위 | amp / dB(−60…0) / sone | 같은 직선이라도 dB·sone이 "고르게 들리는" 페이드 |
| 프리셋 | 평탄·크레센도·디크레센도·스웰 | 빠른 출발점 |
| 기본 게인 | `out = baseGain·e(t)` | 보이스 전체 레벨 |

### 3.4 음색 & 오디오 소스

| 기능 | 수학 | 소리 |
|---|---|---|
| 파형 믹스 | 5파형 배음 합 → PeriodicWave | 밝기와 거칠기 |
| f(x) 파형 | 한 주기 수식 → DFT `a_k` | 직접 설계한 음색 (예: `pulse(x,0.2)`는 비음성) |
| 오디오 소스 f(t) / f′(t) | 곡선 자체 또는 도함수(정규화) | f′(t): 음고가 아니라 **움직이는 속도**를 들음 — 가속 구간이 높은 음 |

### 3.5 구간(Selection)과 레가토

| 기능 | 수학 | 소리 |
|---|---|---|
| 선택 도구 → 로컬 구간 | `y = y_base + w(t)·mix·(y_region − y_base)` | 곡선 일부만 다른 모양으로 갈아끼움. 램프로 경계가 튀지 않음 |
| 구간 솔로/뮤트, gainDb | 구간 창 w(t) | 긴 글리산도의 한 부분만 강조/제거 |
| 레가토 연결 | `φ(t) = 2π∫f dτ` 를 경계에서 초기화하지 않음 | 맞닿은 보이스 사이에 "뚝"(위상 재시작)이 없어짐. 여러 보이스가 한 줄처럼 이어짐 |
| f′(t) 보기 | 도함수 표시 | f′가 불연속인 곳 = 궤적의 모서리(귀에는 "꺾임") |

### 3.6 보이스 생성 프리셋 (다중 보이스)

| 프리셋 | 수식 | 소리 |
|---|---|---|
| 수렴 클러스터 | `f₀ᵢ = C + offsetᵢ`, 모두 `f₁ = T` | 퍼진 화음이 한 음으로 빨려 들어감 (Metastaseis 끝부분 느낌) |
| 엇박 카논 | `f₀ᵢ = C + trᵢ, f₁ᵢ = T + trᵢ, startᵢ = i·stagger` | 같은 글리산도가 이조되며 차례로 진입 |
| 거울 쌍 | `f₁′ = 2C − T − tr` | 위로 가는 선과 아래로 가는 선이 대칭으로 벌어짐 |

## 4. 들어보기 실험

1. **로그 vs 선형**: C3→C6, 곡선 엔진 "다항(직선)"으로 두고 음고 스케일만 바꿔 비교. 선형은 처음 1초에 대부분의 옥타브를 지나가 버립니다.
2. **래칫 σ**: N=12, F₀=C4, F₁=C5. σ 0.02 → 반음계 스케일, σ 0.8 → 거의 연속 글리산도.
3. **맥놀이**: 같은 보이스를 복제하고 한쪽만 +3 센트. 초당 수 회 울렁임이 들립니다.
4. **f′(t) 듣기**: 바운스 엔진을 f′(t) 소스로. 튕길 때마다 음이 치솟는 리듬 패턴이 됩니다.

## 5. 다른 스튜디오와의 관계

- 다른 스튜디오에서 베이킹하면 대부분 **엔진 11(커스텀)** 보이스 + 게인 포인트로 들어옵니다.
- Tempo Studio는 Glissando 보이스의 곡선을 "주제"로 읽어 갈 수 있습니다.
- 버전 갤러리: 스크린샷마다 글리산도 보이스 백업이 생기고 고스트로 겹쳐 비교할 수 있습니다.
