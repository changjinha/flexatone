# 03. Field Studio — 벡터장 위를 나는 입자

> 공통 용어는 [00_공통개념](00_공통개념.md). 화면 조작은 루트의 [field.md](../field.md).

## 1. 목적

**궤적을 그리는 대신 "바람(장)"을 설계하고, 입자가 그 바람을 타고 날아가게 하는 곳**입니다. 입자 하나 = 보이스 하나. 가로축은 시간 t, 세로축은 정규화 음고 y(0 = F₀, 1 = F₁).

직접 그리면 나오지 않는 **물리적으로 그럴듯한 곡선**(관성으로 지나쳤다가 돌아오는 호, 소용돌이 루프, 조율 격자에 달라붙는 음)을 얻기 위한 스튜디오입니다.

## 2. 신호 흐름

```
장 F(t, y) = 가이드 인력 + Σ 힘 노드 + 컬 난류 + 음정 우물 (+ 국소 영역 배율·흐름) + N-체 결합
입자 운동  dv/dt = (F − v)·γ/m           ← 질량 m, 마찰 γ
적분       RK2 중점법, 입자당 221 샘플   ← 편집할 때 한 번 (베이킹)
소리       f(y) = F₀·(F₁/F₀)^y,  게인 ← 유속,  밝기 ← 곡률
```

## 3. 기능별 — 수학적 역할과 소리

### 3.1 입자 물리

| 기능 | 수학 | 소리 |
|---|---|---|
| 질량 m | `dv/dt = (F − v)·γ/m` | 무거우면 장에 늦게 반응해 넓은 호를 그리며 목표를 **지나침(오버슈트)** — 느긋하고 관성 있는 글리산도 |
| 점성 마찰 γ | 장 속도로의 이완율 (동역학엔 γ/m만 작용) | 크면 유선에 착 붙어 장 모양 그대로, 작으면 자기 운동량으로 유선을 가로지름 |
| 발사각 θ₀ / 초속도 v₀ | `v(0) = (v₀cos θ₀, 2v₀ sin θ₀)` | 첫 제스처: 위로 쏘아 올려진 뒤 장에 붙잡힘 |
| 경계 처리 | 탄성 반사(반발계수 e) / 소프트 클램프 / 옥타브 랩 `y mod 1` | 반사: 음역 끝에서 튕김. 랩: 셰퍼드 톤처럼 위로 나가면 아래에서 등장 |
| N-체 결합 c | `Δv_y = Σ 1.4c·sign(yⱼ−y)/(4(|yⱼ−y| + 0.04))` | +: 보이스끼리 모여 유니즌/수렴, −: 서로 피해 성부 간격 유지 |

### 3.2 장 성분

| 성분 | 수학 | 소리 |
|---|---|---|
| 가이드 인력 k | `v_y += g′(t)·min(1, k/2) + 3.5k(g(t) − y)` | 가이드 곡선 g(t)를 스프링처럼 따라감. 0이면 노드·난류만 작용 |
| 인력 노드 | `v += 2.2s·e^(−r²/2R²)·(xₙ − t, yₙ − y)` | 궤적이 한 음/시점으로 빨려 듦 |
| 척력 노드 | 같은 형태, 반대 부호 | 그 음역을 피해 돌아감 → 빈 공간, 우회 |
| 소용돌이 노드 | 접선 방향 `3.2s·e^(−r²/2R²)·(−(yₙ−y), xₙ−t)` | 루프·나선 → 오르내림을 반복하는 비브라토형 소용돌이 |
| 컬 난류 | `v = (∂N/∂y, −∂N/∂x)`, ∇·v = 0 | 발산 없는 노이즈: 입자를 압축하지 않고 휘젓기만 → 자연스러운 흔들림 |
| 음정 우물 | `v_y += 12k·Δy·exp(−Δy²/(2·0.035²))` | 12-TET, 24-TET, 5음 음계, 배음열 위치에 음이 **달라붙음** — 연속 글리산도가 조성적 선율로 |
| 필드 위상 φ | 노드를 ±0.06 궤도로 이동 | φ만 바꿔 닮았지만 조금씩 다른 궤적군(변주) |

### 3.3 국소 영역 (Local Regions)

| 기능 | 수학 | 소리 |
|---|---|---|
| 성분 배율 | `g_c = Π lerp(1, gain_c, w_r(t,y))` | 특정 시간·음역에서만 난류를 끄거나 우물을 강하게 |
| 페더 | `w = 1 − smoothstep(0, feather, sdf)` | 경계에서 궤적이 갑자기 꺾이지 않음 |
| 반전 | `w′ = 1 − w` | "이 영역만 제외" 마스크 |
| 국소 흐름 | `push = w·s·(cos θ, sin θ)` | 특정 구역에서 입자를 원하는 방향으로 밀기 |

### 3.4 흐름 모드와 역행

| 기능 | 수학 | 소리 |
|---|---|---|
| ODE y(t) | `dt/ds = 1` | 시간은 항상 전진. 궤적은 함수 |
| 2D 흐름 | `dt/ds = F_t ∈ [−1.6, 2.4]` | 시간도 장을 따름 → **시간 역행 루프** 가능 (자홍색) |
| 역행 처리: 파라메트릭 펼침 | `y(τ) = y(s=τ)` | 루프를 그대로 음고 제스처로 들려줌 (되돌아가는 곳 = 음고가 거꾸로 흔들림) |
| 역행 처리: 단조 시간 | `y(τ) = y(min{s : t(s) ≥ τ})` | 루프를 건너뛰어 음고가 순간 점프 |

### 3.5 소리 매핑

| 기능 | 수학 | 소리 |
|---|---|---|
| F₀ / F₁ | `f(y) = F₀(F₁/F₀)^y` | 정규화 y를 실제 음역으로 |
| 유속 → 볼륨 | `g = baseGain·clamp(1 − 0.65k + k|v|/|v|max, 0.05, 1.4)` | 빨리 움직이는 구간이 크게 — 스윕이 "휙" 하고 강조됨 |
| 곡률 → 밝기 | `f_c = f·(1.5 + 8kκ/κmax)` | 급하게 꺾일 때 필터가 열려 밝아짐 — 꺾임이 귀에 "반짝"임 |
| 5파형 음색 | 공용 | 곡률→밝기가 톱니/리치 성분을 더함 |

## 4. 들어보기 실험

1. **관성 오버슈트**: 인력 노드 하나, 질량 크게·마찰 작게. 목표음을 지나쳤다 돌아오는 호가 들립니다.
2. **조율 격자**: 음정 우물 5음 음계, 인력 1. 연속 글리산도가 펜타토닉 선율처럼 바뀝니다.
3. **소용돌이 + 2D 흐름**: 시간 역행 루프를 만들고 역행 처리 모드를 바꿔 비교.
4. **N-체 −**: 입자 4개, 결합 음수. 서로 부딪히지 않고 벌어지는 성부.

## 5. 베이킹 시 손실

들리는 궤적(역행 모드 반영)이 커스텀 스플라인으로, 유속→볼륨은 게인 엔벨로프로 옮겨집니다. **곡률→밝기 필터는 사라집니다.**
