# 05. Chaos Studio — 나비효과를 듣기

> 공통 용어는 [00_공통개념](00_공통개념.md).

## 1. 목적

**카오스 동역학계를 글리산도로 소리화**합니다. N개의 보이스가 끌개(attractor) 위의 **거의 같은 점**에서 출발합니다. 처음엔 유니즌처럼 같이 움직이다가, 아주 작은 차이가 지수적으로 커져 어느 순간 각자 다른 길로 갈라집니다. 이 "갈라지는 순간"이 이 스튜디오의 음악적 사건입니다.

결정론적이지만 예측 불가능한 선율, 주기 배가(2 → 4 → 8 → 카오스)로 가는 리듬 구조를 얻는 것이 목적입니다.

## 2. 신호 흐름

```
시스템 ẋ = f(x; 파라미터)  (흐름) 또는  xₙ₊₁ = g(xₙ)  (사상)
  → 과도 구간 버리기 → 끌개 위 기준점 x̄
  → 보이스 i: xᵢ(0) = x̄ + spread·i·uᵢ   (uᵢ = 시드 난수 방향)
  → 고정 dt RK4 적분 (시뮬 시간을 곡 길이에 압축)
  → 매핑: 관측량(x, y, z, 속력, 곡률, 반지름 …) → 음고 / 게인 / 밝기
  → 오실레이터 (게인 · 1/√N, 스테레오 폭)
```

## 3. 기능별 — 수학적 역할과 소리

### 3.1 시스템

| 시스템 | 방정식 | 소리의 성격 |
|---|---|---|
| 로렌츠 | `ẋ=σ(y−x), ẏ=x(ρ−z)−y, ż=xy−βz` (σ10, ρ28, β8/3) | 두 날개 사이를 불규칙하게 오감 → 두 음역을 예측 불가하게 오가는 선율. λ≈0.9로 빨리 갈라짐 |
| 뢰슬러 | `ẋ=−y−z, ẏ=x+ay, ż=b+z(x−c)` | 접힌 나선 하나 → 반복되는 듯 조금씩 다른 오르내림. λ≈0.07로 매우 천천히 갈라짐 |
| 더핑 | `ẍ+δẋ+αx+βx³=γcos ωt` | 이중 우물 스프링. 두 음 사이를 박자감 있게 넘나듦. γ=0.37 카오스, 0.28 주기 2 |
| 토머스 | `ẋ=sin y − bx` (순환) | 미로 같은 흐름. b가 작으면 격자를 떠도는 랜덤 워크 |
| 아이자와 | 구 껍질 + z축 관 | 큰 원을 그리다 관을 따라 솟구침 |
| 이중 진자 | 라그랑주, 마찰 없음 (θ₁, θ₂, ω₁, ω₂) | 팔이 넘어갈 때 θ₂(펼친 각)가 계속 증가 → 연속 상승/하강 |
| 로지스틱 사상 | `xₙ₊₁ = r·xₙ(1−xₙ)` | 반복 1회 = 음 1개. r에 따라 고정음 → 2음 교대 → 4음 → … → 카오스 |
| 에농 사상 | `x′=1−ax²+y, y′=bx` | 부메랑 프랙털 위의 불규칙 선율 |

### 3.2 앙상블 (나비효과의 핵심)

| 기능 | 수학 | 소리 |
|---|---|---|
| 보이스 수 N | 1–16 사본 | 유니즌 → 분기되는 합창 |
| 초기 간격 spread | `log₁₀` 단위, `t_div ≈ ln(0.1·D/spread)/λ` | 10배 작게 할 때마다 갈라짐이 `ln10/λ`만큼 늦어짐(로렌츠 ≈ 2.6 시뮬초). **갈라지는 시점을 작곡**하는 손잡이 |
| 시드 | 초기 흔들림과 섭동 방향 | 같은 시드 = 같은 곡. 다른 시드 = 다른 분기 패턴 |
| 파라미터 스윕 | `p(t) = from + (to−from)·t/T` | 곡 진행에 따라 시스템 성격이 바뀜. 로지스틱 r 스윕 = 주기 배가를 귀로 따라가기 |

### 3.3 적분 설정

| 기능 | 수학 | 소리 |
|---|---|---|
| dt | RK4, 오차 ∝ dt⁴ | 너무 크면 궤적이 부정확(다른 카오스). 스텝 예산 300만 초과 시 자동 확대 |
| 과도 구간 | 버리는 초기 구간 | 끌개에 올라탄 뒤부터 소리 |
| 시뮬 시간 / 곡 길이 | 음악 1초당 시뮬 초 | 시뮬 시간이 길면 움직임이 빨라지고 더 일찍 갈라짐 |

### 3.4 매핑 (상태 → 소리)

| 기능 | 수학 | 소리 |
|---|---|---|
| 소스 | x, y, z, 속력, 곡률 `κ=|v×a|/|v|³`, 반지름, θ₂ 등 | 무엇을 "들을지". 속력은 흥분도, 곡률은 꺾임 순간 |
| 정규화 | `u = (값−p₂)/(p₉₈−p₂)` (기준 궤적 200 시뮬초 또는 보이스별) | 범위를 안정적으로 맞춰 보이스끼리 비교 가능 |
| 음고 채널 | `midi = lo + (hi−lo)·curve(u)` | 하한 > 상한도 허용(반전) |
| 응답 곡선 | expo `(e^{3u}−1)/(e³−1)`, log, smooth | 범위의 어느 쪽을 더 넓게 쓸지 |
| 양자화 | 12-TET 또는 스케일 | 카오스 선율을 음계 위로 |
| 슬루 | `y += (1−e^{−1/(τ·rate)})(x−y)` | 양자화 계단 사이 포르타멘토 |
| 게인 채널 | 소스 → 진폭, × baseGain/√N | 예: 속력 → 게인이면 빠른 구간이 큼 |
| 밝기 채널 | `f_c = f·(1.5 + 10·양·밝기)` | 저역통과 필터 개방 |
| 사상: 유지/글라이드, 속도 | 반복마다 음 유지(5 ms 슬루) 또는 선형 글라이드 | 또렷한 음표열 vs 미끄러지는 선율. 속도 = 초당 음 수 |

### 3.5 분석

| 기능 | 수학 | 의미 |
|---|---|---|
| λmax (베네틴) | `λ = (1/T)Σ ln(dₖ/d₀)`, 10⁻⁸ 짝 궤적 재정규화 | 혼돈의 세기. 클수록 빨리 갈라짐 |
| 발산 그래프 | `d(t) ≈ d(0)e^{λt}` (로그 눈금) | 곧은 오르막 = 지수 성장. 빨간 선(0.1×끌개 지름) 통과 = 발산 시각 |
| 분기도 | 파라미터별 장기 x 값 (사상) | 지금 어느 영역(주기/카오스)인지 |

## 4. 들어보기 실험

1. **갈라짐 시점 조절**: 로렌츠, N=4, spread −6 → −3. 갈라지는 순간이 약 2.6 시뮬초씩 앞당겨집니다.
2. **주기 배가 듣기**: 로지스틱, 스윕 r 2.8 → 4.0, 유지 모드, 양자화 켜기. 한 음 → 두 음 교대 → 네 음 → 혼돈.
3. **같은 시스템, 다른 관측량**: 로렌츠에서 음고 소스를 x → z → 속력으로 바꿔 보세요. 같은 운동이 전혀 다른 선율이 됩니다.

## 5. 베이킹 시 손실

보이스 하나가 이어 붙은 커스텀 스플라인 보이스 하나 이상(최대 64). 유지 모드는 정확한 계단. **스테레오 폭(팬)과 밝기 필터는 사라집니다.**
