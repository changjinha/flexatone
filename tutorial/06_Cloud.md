# 06. Cloud Studio — 확률로 만드는 글리산도 구름 (크세나키스)

> 공통 용어는 [00_공통개념](00_공통개념.md).

## 1. 목적

개별 음을 쓰지 않고 **통계로 소리를 작곡**합니다. 수십~수천 개의 짧은 글리산도 입자를 확률분포에서 뽑아, "언제 얼마나 많이(밀도)", "어느 음역에 얼마나 퍼져서(분포)", "어느 방향으로 미끄러지며(기울기)" 울릴지만 정합니다.

크세나키스의 확률 음악(*Pithoprakta*, *Achorripsis*)과 체 이론(sieve), 리게티의 클러스터 수렴을 다루는 스튜디오입니다. 듣는 것은 개별 음이 아니라 **질감(texture)**입니다.

## 2. 신호 흐름

```
밀도 λ(t)            → 비균질 포아송 과정 → 이벤트 시각 tₖ
중심 c(t), 폭 w(t),  → 음고 분포 p = c + w_eff·X,  X ~ 분포
수렴 k(t)               w_eff = w·(1 − k)
체 (sieve)           → 허용 음고로 끌어당김 또는 버림
글라이드             → p1 = p0 ± 기울기·길이  또는  p1 ~ 분포(끝 시각)
길이·게인·팬 분포    → 이벤트 {t0, dur, p0→p1, gain, pan}
                     → 동시발음 상한, 자동 레벨 0.6/√(평균 중첩) → 스케줄러
```

모든 무작위는 시드에서 나오는 **5개 독립 스트림**(시각·음고·글라이드·길이·게인/팬)입니다. 그래서 음고 분포만 바꿔도 이벤트 시각은 그대로입니다.

## 3. 기능별 — 수학적 역할과 소리

### 3.1 시간 곡선 4개 (곡선 엔진으로 성형)

모두 `v(t) = lo + (hi − lo)·y(t/T)`.

| 곡선 | 수학 | 소리 |
|---|---|---|
| 밀도 λ(t) | `tₖ = Λ⁻¹(E₁+…+Eₖ)`, `Eᵢ ~ Exp(1)`, 기대 개수 `∫λ dt` (0.2–200/초) | 낮으면 점점이 떨어지는 빗방울, 높으면 쏴— 하는 소나기. 곡선으로 크레센도 같은 "밀도 크레센도" |
| 중심 c(t) | 분포의 위치 (MIDI) | 구름 전체가 떠오르거나 가라앉음 |
| 폭 w(t) | 균등 반폭 / 가우스 σ / 코시 γ … | 좁으면 한 음 주변 웅성거림, 넓으면 전 음역을 덮는 구름 |
| 수렴 k(t) | `w_eff = w(1 − k)` | 1로 가면 모든 입자가 한 점으로 빨려 듦 (리게티 수렴) |

### 3.2 음고 분포

| 분포 | 수학 | 소리 |
|---|---|---|
| 균등 | U(−1,1) | 음역 안이 고르게 채워진 평평한 구름 |
| 가우스 | Box–Muller | 중심에 몰리고 가장자리는 드문 자연스러운 덩어리 |
| 코시 | 두꺼운 꼬리 | 대부분 중심 근처지만 **가끔 멀리 튀는 음** |
| 로지스틱 | 가우스와 비슷, 꼬리 약간 두꺼움 | 가우스보다 조금 더 거친 가장자리 |
| 레비 안정 (α) | Chambers–Mallows–Stuck, 1<α≤2 | α가 작을수록 큰 도약 — "레비 비행"처럼 갑자기 먼 음역으로 점프 |
| 브라운 보행 | `pₖ = reflect(pₖ₋₁ + d + s·N(0,1))` | 이전 음 근처에서 다음 음이 나옴 → 구름이 **선율처럼 떠돌아다님**. 표류 d>0이면 서서히 상승 |

범위 밖 표본은 최대 8회 다시 뽑고 그래도 벗어나면 잘라냅니다.

### 3.3 크세나키스 체 (Sieve)

| 기능 | 수학 | 소리 |
|---|---|---|
| 체 항 | `(n − 이동) mod m ∈ 나머지` | 잉여류 하나 = 등간격 음 집합 (예: mod 3 = 감7화음 격자, mod 4 = 증3화음) |
| 합집합 / 교집합 | `S = ∪ₖ(mₖℤ + Rₖ)` 또는 ∩ | 여러 격자를 합쳐 비대칭 음계를 만듦 — 반복되지 않는 독특한 선법 |
| 격자 단계 | 반음 / 사분음 / 팔분음 | 미분음 체 |
| 끌어당김 켬/끔 | 가장 가까운 원소로 이동 / 체 밖 시작음 버림 | 켜면 밀도 유지, 끄면 밀도가 줄고 순수한 체만 남음 |

### 3.4 글라이드·길이·게인

| 기능 | 수학 | 소리 |
|---|---|---|
| 글라이드: 기울기 | `p1 = p0 ± |평균 + 편차·N(0,1)|·길이` | 모든 입자가 비슷한 각도로 미끄러짐 → 방향성 있는 비 |
| 글라이드: 목표음 | p1을 끝 시각 분포에서 다시 뽑음 | 구름이 이동하면 입자도 따라감 |
| 상승 비율 | 위로 갈 확률 0–1 | 0.5 = 반반, 1 = 모두 상승 (떠오르는 느낌) |
| 글라이드 곡선 | Hz 지수 = MIDI 직선 | 고르게 들리는 짧은 스윕 |
| 길이 분포 | 지수 / 로그정규(σ_ln 0.6) / 균등, [최소, 최대] | 짧으면 "톡톡" 점묘, 길면 겹치는 선의 천 |
| 게인 | `base·(1 + 편차·U(−1,1))` | 셈여림의 무작위성 |
| 음고 보정 | 역 A-가중 절반 (−6…+12 dB) | 낮은/아주 높은 입자가 묻히지 않게 |
| 포락선 | Hann sin²(πx) / Tukey / 지수 감쇠 | Hann은 부드러운 입자, 지수 감쇠는 "핑" 하는 타격감 |
| 자동 레벨 | `g = 0.6/√max(1, Σdur/T)` | 밀도를 바꿔도 비슷한 음량 |
| 최대 동시발음 | 넘으면 가장 조용한 이벤트 제거 | CPU·음량 안전장치 |
| 스테레오 폭 | 이벤트별 무작위 팬 × 폭 | 공간에 흩뿌려진 구름 |

### 3.5 분석 뷰

| 뷰 | 수학 | 의미 |
|---|---|---|
| 음고 히스토그램 vs 이론 | `n_b ≈ N·pdf(p_b)·Δp` | 실제 뽑힌 음이 분포를 따르는지 눈으로 확인 |
| 이벤트 산점도 | p0→p1 선분, 굵기=게인 | 보라 띠 = 중심 ± 유효 폭 |

## 4. 들어보기 실험

1. **분포 비교**: 같은 시드, 폭 12, 분포만 균등 → 가우스 → 코시 → 레비(α 1.2). 꼬리가 두꺼워질수록 "튀는 음"이 늘어납니다.
2. **리게티 수렴**: 수렴 곡선을 0 → 1 지수형으로. 넓은 구름이 한 음으로 좁아집니다.
3. **밀도 크레센도**: λ를 1 → 100. 빗방울에서 폭우로.
4. **체 정원**: mod 3 ∪ mod 4 + 끌어당김. 반음계 구름이 독특한 선법으로 바뀝니다.

## 5. 베이킹 시 손실

이벤트를 구간 그래프 색칠로 **최대 64개 레인**에 묶어 레인마다 보이스 하나. 64개를 넘는 중첩은 가장 조용한 이벤트부터 제외. **스테레오 팬과 오실레이터 위상은 사라지고**, 포락선은 이벤트당 약 7개 게인 점으로 근사됩니다.
