# 09. Fractal Studio — 자기유사 궤적과 보이스 트리

> 공통 용어는 [00_공통개념](00_공통개념.md).

## 1. 목적

**확대해도 같은 모양이 되풀이되는(자기유사)** 음고 궤적을 만듭니다. 큰 윤곽 안에 같은 모양의 작은 윤곽이, 그 안에 더 작은 윤곽이 들어 있습니다. 귀로는 "큰 프레이즈 = 작은 장식들의 확대판"처럼 들립니다.

여섯 가지 생성기는 각각 프랙탈을 만드는 다른 수학(반복 함수계, 랜덤 프랙탈, 무한 급수, 칸토어 집합, 문자열 재작성, 무한 급수 캐논)입니다. **진행적 정밀화**로 "윤곽 먼저, 세부 나중"이 쌓이는 과정을 들을 수도 있습니다.

## 2. 신호 흐름

```
생성기 (6모드) → 정규화 곡선 y(x) 또는 보이스 트리
  → (정밀화: 단계 k까지 합한 곡선 = 보이스 k, 시작 어긋남)
  → 음역 매핑  midi = lo + y·(hi − lo)  → 양자화(선택)
  → 게인: 고정 또는 기울기 |y′|
  → 조밀한 배열로 베이킹 (50–800 pts/s, 최대 40만 샘플)
  → 오실레이터, 믹스 × 1/√(최대 동시 보이스)
```

## 3. 생성기별 — 수학적 역할과 소리

### 3.1 프랙탈 보간 (반슬리 FIF)

| 파라미터 | 수학 | 소리 |
|---|---|---|
| 보간점 (2–9) | 곡선이 반드시 지나는 점 | 큰 선율 윤곽(골격 음) |
| 수직 스케일 dₖ | 어파인 사상 `wₖ(x,y) = (aₖx+eₖ, cₖx+dₖy+fₖ)`, |d|<1 | 각 구간에 전체 곡선의 축소 사본이 얼마나 강하게 들어가는지. 0 = 직선, |d|→1 = 거칠고 꽉 찬 장식, 음수 = 뒤집힌 사본 |
| 반복 깊이 | 꺾은선에서 시작한 반복 횟수 | 깊을수록 세부가 한 세대씩 추가 |

`Σ|dₖ| > 1`이면 그래프 차원 D > 1 (진짜 프랙탈).

### 3.2 분수 브라운 운동 (fBm)

| 파라미터 | 수학 | 소리 |
|---|---|---|
| 허스트 지수 H | 스펙트럼 `Aₖ ∝ k^−(H+½)`, `Var[Δy] ∝ δ^(2H)`, D = 2 − H | H 낮음(0.1): 들쭉날쭉한 해안선 — 신경질적으로 떨리는 선율. H 높음(0.9): 부드럽게 떠도는 표류 |
| 옥타브 수 | 단계 j가 배음 2^j…2^(j+1)−1 추가 | 세부의 미세함 |
| 합성 방식 | 코사인 스펙트럼 합 / 재귀 중점 변위(σ를 2^−H씩 축소) | 결과는 비슷, 질감 미묘하게 다름 |
| 시드 | 위상 φₖ | 같은 통계, 다른 모양 |

### 3.3 바이어슈트라스 / 다카기

| 파라미터 | 수학 | 소리 |
|---|---|---|
| 진폭 비 a | `y = Σ aᵏ cos(bᵏπx)` | 클수록 거침 |
| 주파수 비 b | ab > 1이면 어디서도 미분 불가 | 층층이 빨라지는 떨림이 겹친 궤적. D = 2 + log a/log b |
| 항 수 | 정밀화 단계 | 베이킹 샘플 3개보다 짧은 항은 제외(해상도 경고) |
| 다카기 | 코사인 대신 삼각파 s(2ᵏx) (블랑망제) | 매끄러운 떨림 대신 꺾인 선의 중첩 |

### 3.4 악마의 계단 (칸토어 함수)

| 파라미터 | 수학 | 소리 |
|---|---|---|
| 분할 수 m (홀수) | `(m+1)/2` 조각은 오르고 `(m−1)/2` 간격은 고원 | **오르다 멈추고, 오르다 멈추는** 단조 상승. 멈춤 자체가 계층적 리듬 |
| 제거 비율 | 고원의 총 폭 (고전: 1/3) | 클수록 머무름이 길고 상승이 가파름 |
| 깊이 | 재귀 절단 횟수 | 깊이 6에서 가장 짧은 계단 ≈ 길이/3⁶ |

### 3.5 L-시스템 트리

| 파라미터 | 수학 | 소리 |
|---|---|---|
| 공리 / 규칙 | 문자열 동시 재작성, 예: `F=F[+F]F[-F]F` | 문법이 선율을 키움 |
| A–W | 시간 전진 + 기울기만큼 음고 이동 | 한 걸음 |
| + / − | 기울기 ±회전(반음), 누적 | "++" = 두 배 빠르게 상승 |
| [ ] | 분기: 새 보이스 시작 / 부모 복귀 | **가지 하나 = 보이스 하나**. 나무가 화음으로 자람 |
| 반복 횟수 | 길이 기하급수 증가 (20만 기호 상한) | 가지·보이스 수 증가 |
| 글라이드 | 켬: 스텝 동안 미끄러짐 / 끔: 5 ms 점프 후 유지 | 연속 글리산도 가지 vs 계단 선율 |
| 프리셋 | 조류(피보나치) · 코흐 · 이진 트리 | 피보나치 길이 리듬, 자기유사 윤곽, 분기 화음 |

### 3.6 스케일 캐논 (노르고르 무한 급수)

| 파라미터 | 수학 | 소리 |
|---|---|---|
| 주제 | `a(0)=0, a(2n)=−a(n), a(2n+1)=a(n)+1` → 0,1,−1,2,1,0,−2,3,… | 짝수 번째 음만 모으면 원래 선율의 전위가 나옴 — 선율 안에 자기 자신이 숨어 있음 |
| 층 수 K / 비율 r | 층 k: 길이 × rᵏ, 음정 × rᵏ | r = ½: 층마다 두 배 빠르고 음정은 절반 → 무한 캐논 |
| 음정 단위, 음 길이, 층별 이조 | `mₖ(n) = base + k·T + step·rᵏ·a(n)` | 빠른 층은 미분음이 됨(양자화 안 하면). 이조로 층 분리 |

## 4. 공통 설정

| 기능 | 수학 | 소리 |
|---|---|---|
| 음역 | `midi = lo + y(hi−lo)` | 몇 옥타브에 펼칠지 |
| 양자화 | 끔 / 12-TET / 음계 (5 ms 경계 글라이드) | 프랙탈을 조성 선율로 |
| 진행적 정밀화 | 보이스 k = 단계 k까지 합, 최대 12단계, 시작 어긋남 | 윤곽이 먼저 울리고 세부가 차례로 쌓임 — 프랙탈이 "자라는" 소리. 어긋남 0이면 세부 단계의 합창 |
| 게인 소스: 기울기 | `g = level·(1 − s + s|y′|/|y′|₉₅)` | 빠르게 움직이는 구간이 크게, 고원은 작게 |
| 베이킹 해상도 | 50–800 pts/s | 높을수록 fBm/바이어슈트라스 세부가 더 들림 |
| 분석 (박스 카운팅 D) | `D = lim log N(ε)/log(1/ε)` | 이론값과 비교. 유한 해상도로 조금 낮게 나옴 |
| 줌 렌즈 | 구간을 자체 해상도로 재계산 | 확대해도 닮은 모양 (표시 전용) |

## 5. 들어보기 실험

1. **H 스윕**: fBm, H 0.1 → 0.5 → 0.9. 신경질적 떨림 → 브라운 운동 → 느긋한 표류.
2. **악마의 계단**: m=3, 깊이 5, 길이 20초. 계층적인 멈춤 리듬이 들립니다.
3. **정밀화**: FIF, 단계 0–5, 어긋남 2초. 윤곽에서 장식이 하나씩 피어납니다.
4. **이진 트리**: L-시스템 이진 트리, 반복 4. 한 음에서 갈라져 화음으로 퍼집니다.

## 6. 베이킹 시 손실

RDP로 극값만 남긴 뒤(≤ 48점) 64 앵커 이하 커스텀 스플라인 + 게인 25점. **앵커보다 미세한 세부(fBm, 바이어슈트라스)는 매끄러워집니다** — 오차(반음)가 베이킹 카드에 표시됩니다.
