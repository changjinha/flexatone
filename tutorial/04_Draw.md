# 04. Draw Studio — 그림이 곧 악보 (UPIC)

> 공통 용어는 [00_공통개념](00_공통개념.md).

## 1. 목적

크세나키스의 **UPIC** 시스템처럼, **선을 그리면 그 선이 그대로 글리산도가 되는** 스튜디오입니다. x = 시간(초), y = 음고(MIDI = 로그 Hz), **선 굵기 = 진폭**.

곡선 엔진으로는 표현하기 어려운 즉흥적인 손 제스처, SVG 그림, 여러 획의 군집을 빠르게 소리로 만드는 것이 목적입니다. 수학적으로는 "울퉁불퉁한 손 입력 → 깨끗하고 연주 가능한 함수"로 바꾸는 **신호 정리 파이프라인**이 핵심입니다.

## 2. 신호 흐름

```
포인터 샘플 (t, p, 압력)
  → 변환 (역행·반전·조옮김·늘이기)        ← 비파괴: 항상 원시 점에서 재계산
  → 시간 역행 처리 (삭제 / 분할 / 호 길이)
  → 음고 스냅 (반음·사분음·음계, 강도)
  → RDP 단순화 + 스플라인 근사 (허용오차 ε)
  → 커스텀 스플라인 (보이스 하나 = 단조 구간 하나)
  → 오실레이터, 게인 = baseGain · lerp(1, 두께, depth)
```

## 3. 기능별 — 수학적 역할과 소리

### 3.1 그리기 도구

| 도구 | 역할 | 소리 |
|---|---|---|
| 그리기 (D) | 모든 포인터 샘플 기록, 펜 압력 → 두께 | 손떨림까지 담긴 유기적 글리산도 (매끄럽게로 정리) |
| 직선 (L) | 두 점 직선, Shift = 반음 스냅 | 일정 속도의 깨끗한 스윕 |
| 선택/이동 (V) | 시간·음고 평행이동 | 같은 제스처를 다른 시점/음역으로 |
| 노드 (N) | 스플라인 앵커 직접 편집 | 정밀 수정 ("스플라인 직접 편집" 모드) |
| 지우기 (E) | 점 삭제, 가로지르면 획 절단 | 선을 끊으면 별도 보이스로 쪼개짐 |
| 펜 두께 | 압력 없는 장치의 두께 0–1 | 두께 = 진폭. 0이면 무음 |

### 3.2 신호 정리

| 기능 | 수학 | 소리 |
|---|---|---|
| 매끄럽게 | 허용오차 `ε = 0.04 + 2·smooth^1.5` 반음, RDP 단순화 + 스플라인 근사. 척도 1초 = 12반음(등방성) | 낮으면 손떨림이 미세 비브라토로 남음, 높으면 큰 윤곽만 남은 매끄러운 글리산도 |
| 근사 결과 | 원시 점 수 → 앵커 수, RMSE | 단순화가 소리를 얼마나 바꿨는지 수치 |
| 음고 스냅 | `p′ = lerp(p, snap(p), strength)` (MIDI 공간) | 1이면 음계 위에 붙은 선율, 0.5면 음계 쪽으로 기우는 글리산도 |
| 음계 / 근음 | 장·단·5음·온음 (센트 오프셋 저장) | 스냅 대상 집합 |

### 3.3 시간 역행 처리

보이스는 시간의 함수여야 하므로, 왼쪽으로 되돌아가는 선에는 규칙이 필요합니다.

| 모드 | 수학 | 소리 |
|---|---|---|
| 삭제 | 뒤로 가는 점 제거 | 루프가 사라지고 단조로운 선만 |
| 분할 | 방향이 바뀔 때마다 별도 보이스 | 고리 모양이 겹치는 여러 성부로 (64개 초과 시 경고) |
| 호 길이 | `t = t₀ + s/v`, `s = Σ√((12Δt)² + Δp²)` | 그린 선을 **따라가며** 재생. 화면에서 뒤로 가도 소리는 계속 진행 — 원을 그리면 음고가 원운동 |
| 호 속도 | 초당 이동하는 반음 환산 길이 | 12면 평평한 획이 그린 속도대로 |

### 3.4 변환 & 에코 (모두 비파괴)

| 기능 | 수학 | 소리 |
|---|---|---|
| 역행 | 중심 기준 시간 반전 | 같은 제스처를 거꾸로 |
| 반전 | 획 음역 중심 기준 음고 뒤집기 | 상승 ↔ 하강 (전위) |
| 조옮김 | `p + Δ` 반음 | 음역 이동 |
| 시간 늘이기 | 시작점 기준 길이 배율 | 같은 모양을 더 느리게/빠르게 |
| 에코 캐논 | 복제 k: `t + kΔt`, `p + kΔp`, `gain·decayᵏ` | 지연·이조·감쇠되는 메아리 → 카논 텍스처 |

### 3.5 소리

| 기능 | 수학 | 소리 |
|---|---|---|
| 게인 원천 | 두께(UPIC) 또는 고정 | 두께면 붓 압력이 셈여림 |
| 두께 → 게인 깊이 | `g = baseGain·lerp(1, w, depth)` | 0이면 두께 무시, 1이면 두께 그대로 |
| 음색 | 공용 5파형 | |
| 프리셋 | 상승 호 · UPIC 군집(시드 12획) · 거울 캐논 | 출발점 |
| SVG 가져오기 | 경로 샘플링 → 획, 닫힌 도형은 위/아래 절반 분할 | 로고·도형이 그대로 화음 글리산도로 |

## 4. 들어보기 실험

1. **매끄럽게 0 vs 1**: 손으로 물결선을 그리고 비교. 0은 떨림이 들리고 1은 큰 호만 남습니다.
2. **원 그리기**: 역행 처리 "분할"과 "호 길이" 비교. 분할은 위/아래 두 성부, 호 길이는 음고가 오르내리는 한 줄.
3. **에코 캐논**: Δt 0.5초, Δp +5, decay 0.7. 4도씩 올라가며 사라지는 메아리.

## 5. 베이킹 시 손실

획 조각마다 커스텀 스플라인 보이스(최대 64). 조밀한 두께 곡선은 **게인 17점**으로 줄어듭니다.
